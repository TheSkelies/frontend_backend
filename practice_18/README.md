# Отчёт по 3 контрольной работе

## Практическая работа 13 Service Worker

- **Добавление заметок:** была реализована страница с добавлением заметок
- **Сохранение заметок:** было реализовано сохранение добавленных заметок в localStorage
- **Кеширование:** было реализовано кеширование страницы с созданными заметками и их загрузка для доступа при отсутствии подключения к интернету

## Практическая работа 14 Web App Manifest
- **Создание манифеста:** был создан файл manifest.json, который описывает данные приложения
- **Добавлен набор иконок:** в манифест были добавлены иконки разных размеров
- **Тестирование:** манифест был проверен на правильность работы

## Практическая работа 15 HTTPS + App Shell
- **Настройка локального HTTPS:** была совершена настройка по запуске сервера на защищённом протоколе HTTPS
- **App shell:** реализована первичная загрузка приложения при недостаточном подключении к интернету
- **Добавлен новый кэш:** добавлен кэш, содержащий в себе статические данные

## Практическая работа 16 WebSocket + Push
- **Рассылка уведомлений:** реализована рассылка системных уведомлений о создании заметки
- **Система подписки:** реализована система подписки на рассылку, позволяющая отключать уведомления
- **Реализована двусторонняя связь:** реализована связь между сервером и клиентом в реальном времени, позволяющая рассылать уведомления

- **Изменение структуры заметок:** в структуру заметки добавлено время напоминания
- **Реализация напоминаний:** реализована система отправки напоминаний в заданное время
- **Реализация откладывания напоминаний:** реализована система откладывания напоминаний на 5 минут
