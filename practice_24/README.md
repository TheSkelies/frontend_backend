# Отчёт по 4 контрольной работе

**В ходе выполнения контрольной работы 4 были выполнены практики с 19 по 23**

## Практическая работа 19 Работа с реляционными СУБД на примере PostgreSQL

- **Подключение СУБД к Node.js:** было освоено подключение СУБД (на примере PostgreSQL) с помощью библиотеки Sequelize 
- **Особенности объектно-реляционной СУБД:** были освоены особенности хранения данных в объектно-реляционной СУБД такой, как PostgreSQL
- **Создание API:** была создана работующая API для управления пользователями с подключенной СУБД PostgreSQL

## Практическая работа 20 Работа с NoSQL СУБД на примере MongoDB
- **Подключение СУБД к Node.js:** было освоено подключение СУБД (на примере MongoDB) с помощью библиотеки Mongoose
- **Особенности NoSQL СУБД:** были освоены особенности хранения данных в NoSQL СУБД такой, как MongoDB
- **Создание API:** была создана работующая API для управления пользователями с подключенной СУБД MongoDB

## Практическая работа 21 Кэширование с использованием Redis
- **Redis:** было освоено in-memory хранилище данных типа ключ-значение, которое предназначено для хранения кэша, сессий, очередей и временных данных
- **Реализация:** была реализована система записи временных данных в кэш для ускорения работы приложения и уменьшения нагрузки на сервер, путём загрузки данных из кэша
- **Тестирование:** были проведены успешные тесты, которые указывают на загрузку данных из кэша

## Практическая работа 22 Балансировка нагрузки в веб-приложениях
- **Балансировка нагрузки:** был освоен механизм балансировки нагрузки, его цели и возможности
- **Алгоритмы балансировки:** были освоены основные алгоритмы распределения запросов на сервера: Round Robin (последовательное распределение запросов), Least Connections (распределение запросов на основе загруженности серверов) и IP Hash (распределение запросов на основе IP-адреса с которого поступил запрос)
- **Реализация:** была реализована балансировка нагрузки на основе алгоритма Round Robin
- **Тестирование:** были проведены успешные тесты, указывающие на использование алгоритма Round Robin

## Практическая работа 23 Контейнеризация приложений с Docker
- **Docker:** была установлена платформа Docker, изучены её ключевые понятия, цели и возможности 
- **Dockerfile:** был создан Dockerfile, в котором указываются настройки контейнеризации 
- **docker-compose:** был создан файл docker-compose.yml, позволяющий управлять всеми контейнерами одновременно
- **Реализация:** было создано API, обеспечивающее поддержку нескольких серверов
